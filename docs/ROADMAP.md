# Chaos Roadmap

Chaos 的开发路线遵循一个原则：先成为可靠的本地写作工具，再逐步成为有深度记忆和故事智能的小说创作系统。

## v0.1 Alpha - 基础本地写作闭环

状态：已于 2026-07-14 完成。

目标：能真实作为本地写作工具使用。

核心能力：

- 填写作品信息并在软件私有作品库中新建项目；可打开已有项目。
- 项目文件夹 + `.moqi/project.sqlite`。
- 章节正文保存到 SQLite。
- 自动同步 Markdown 镜像。
- TXT / Markdown 导出。
- 基础错误提示和保存状态。

## v0.2 Writing UX - 写作体验打磨

状态：下一 Milestone，尚未启动。

目标：让作者愿意每天打开 Chaos 写作。

核心能力：

- 章节新增、重命名、删除、排序。
- 大纲页摘要编辑和状态切换。
- 自动保存状态、今日字数、章节字数。
- 手动版本快照。
- SQLite FTS5 全文搜索。
- 可折叠检查器与小屏体验。

## v0.3 Storyline - 大纲与故事线工作台

目标：让大纲和故事线成为真正独立的一等工作区。

核心能力：

- 事件增删改查。
- 故事时间线和叙事顺序视图。
- 图谱节点增删改查。
- 人物、事件、章节、伏笔之间的关系连线。
- 伏笔状态流转。
- 图谱节点跳转到章节、人物卡、伏笔卡。

## v0.4 AI Assist - 可控 AI 建议

目标：AI 先做可审查的建议，不自动改作者设定。

核心能力：

- OpenAI、Anthropic、Gemini、OpenAI-compatible provider 配置。
- API Key 存系统 keychain。
- 润色选段、章节总结、人物变化提取、伏笔候选提取。
- 上下文范围可选：minimal、chapter、project-summary。
- AI 输出进入 `MemoryPatch` 队列。

## v0.5 Auto Dream - 手动潜意识整理

目标：把后台潜意识从概念变为可手动运行的整理器。

核心能力：

- 手动分析当前章节或最近章节。
- 章节摘要压缩为卷级摘要建议。
- 人物状态、关系、目标变化建议。
- 伏笔回收 / 发展状态建议。
- Auto Dream 运行记录、失败记录、上下文消耗估算。

## v0.6-v0.8 专业写作套件

- DOCX / EPUB 导出。
- 分卷、分部、资料夹、素材库。
- 标签、筛选、批量操作。
- 更完整的版本历史和回滚。
- 导入 TXT、Markdown、DOCX。

## v0.9-v1.0 记忆系统成熟

- 双域三层记忆完整落库。
- Global Memory 跨项目复用作者偏好。
- Project Memory 维护世界观、规则、人物关系、事件因果。
- MemoryPatch 支持批量审核、差异对比、证据追踪。

## v1.x 故事智能与图谱深化

- 大型图谱性能优化。
- 节点模板、故事结构模板、AI 工作流模板。
- 时间线矛盾检测。
- 人物动机和关系变化检测。
- 图谱与正文双向引用。

## v2.x 生态与扩展

- 插件系统。
- 本地模型适配。
- 多项目资料库。
- 只读分享或协作模式。
- 更强的跨软件迁移能力。
