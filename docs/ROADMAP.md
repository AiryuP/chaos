# Chaos 路线图

本路线图同时记录长期方向、版本范围和完成进度，不是开发准入规则。用户可以根据实际需求调整顺序或提前实现某项能力；当需求超出当前进度参考时，Codex 负责提示影响，由用户决定。

Chaos 的总体路线是：先成为可靠的本地写作工具，再逐步发展为具有深度记忆和故事智能的小说创作系统。

## v0.1 Alpha - 基础本地写作闭环

进度：已于 2026-07-14 完成。

已完成范围：

- 作品信息创建、软件私有作品库和已有项目打开。
- Electron main、preload、renderer 的受控通信。
- SQLite schema 和项目迁移版本。
- 章节正文保存、加载和更新。
- Markdown 镜像同步。
- TXT / Markdown 导出。
- 基础错误、保存状态和未保存内容保护。
- 最近项目与托管作品库入口。

## v0.2 Writing UX - 写作体验打磨

进度：规划参考，尚未实现。

规划范围：

- 章节新增、重命名、删除和排序。
- 大纲页摘要编辑和状态切换。
- 自动保存状态、今日字数和章节字数。
- 手动版本快照与恢复路径。
- 基于 SQLite FTS5 的全文搜索。
- 可折叠检查器与较窄窗口体验。

## v0.3 Storyline - 大纲与故事线工作台

规划目标：让大纲和故事线成为真正独立的一等工作区。

- 事件增删改查。
- 故事时间线和叙事顺序视图。
- 图谱节点和连线管理。
- 人物、事件、章节和伏笔之间的关系。
- 伏笔状态流转。
- 从图谱跳转到章节、人物卡和伏笔卡。

## v0.4 AI Assist - 可控 AI 建议

规划目标：AI 先提供可审查建议，不自动修改作者设定。

- OpenAI、Anthropic、Gemini 和 OpenAI-compatible Provider 配置。
- API Key 保存到系统 keychain。
- 选段润色、章节总结、人物变化提取和伏笔候选提取。
- 可配置上下文范围。
- AI 输出进入 `MemoryPatch` 审核队列。

## v0.5 Auto Dream - 潜意识整理

规划目标：把长期内容整理成可检查、可追溯的辅助流程。具体触发方式在实现时再决定，不在路线图中提前锁定。

- 分析当前章节或最近章节。
- 将章节摘要压缩为卷级摘要建议。
- 生成人物状态、关系和目标变化建议。
- 生成伏笔回收或发展状态建议。
- 保留运行记录、失败记录和上下文消耗估算。

## v0.6-v0.8 专业写作套件

- DOCX / EPUB 导出。
- 分卷、分部、资料夹和素材库。
- 标签、筛选和批量操作。
- 更完整的版本历史和回滚。
- 导入 TXT、Markdown 和 DOCX。

## v0.9-v1.0 记忆系统成熟

- 双域三层记忆完整落库。
- 全局记忆跨项目复用作者偏好。
- 项目记忆维护世界观、规则、人物关系和事件因果。
- `MemoryPatch` 支持批量审核、差异对比和证据追踪。

## v1.x 故事智能与图谱深化

- 大型图谱性能优化。
- 节点模板、故事结构模板和 AI 工作流模板。
- 时间线矛盾检测。
- 人物动机和关系变化检测。
- 图谱与正文双向引用。

## v2.x 生态与扩展

- 插件系统。
- 本地模型适配。
- 多项目资料库。
- 只读分享或协作模式。
- 更强的跨软件迁移能力。
